# godotgame fixture (Godot 4 PCK)

Small Godot 4 project (`src/`): `project.godot` (main scene, `SaveSystem` autoload, input map), scenes `scenes/main.tscn`
(Node2D + instanced player + `AudioStreamPlayer` "AudioPlayer" + `HUD/ScoreLabel`) and `scenes/player.tscn` (CharacterBody2D,
ColorRect, RectangleShape2D sub-resource), scripts `player.gd` (movement from `move_*` actions), `save_system.gd`
(writes/reads `user://save.json`), `main.gd` (score label, audio on `collect`, save on close), and `audio/beep.wav`
(0.12 s 440 Hz sine, 16-bit mono 22050 Hz, generated by `src/make_wav.py`, checked in).

## Build
`./build.sh` runs `src/pack_pck.py pack` (pure Python Godot 4 PCK writer, pack format 2, engine fields 4.3.0, 32-byte alignment,
sorted entries, MD5 per file, no timestamps) -> `original/game.pck` (11680 bytes, 7 entries), then `pack_pck.py verify` (own parser,
md5 and byte comparison with `src/`), writes `original/godotgame.x86_64.README` (the engine binary is **not redistributed**).
`pack_pck.py` documents the exact layout in its docstring. Cross-check: the first 100 header bytes are byte-identical to
`gdre_tools --pck-create --pck-version=2 --pck-engine-version=4.3.0` output for the same files (flags = 0 for 4.3).

## Verified with GDRE tools 2.7.0 (headless)
`gdre_tools.x86_64 --headless --recover=original/game.pck --output=<dir>`: "Detected Engine Version: 4.3.0", "Verified 7 files, no errors
detected", "Extracted 7 files, no errors detected"; the recovered tree is byte-identical to `src/` (minus the two build tools).
`--list-files` lists the 7 `res://` entries. GDRE warns "No import files found" (expected, see limits).

## Features (stable ids)
Recoverable (`linux_via_gdre`): `godotgame.pck_recover`, `godotgame.engine_version_detect`, `godotgame.scripts_recover`,
`godotgame.scenes_recover`, `godotgame.audio_asset`, `godotgame.project_settings`.
Runtime (`godot_engine_only`, **no expected values, not executable here**): `godotgame.player_movement`, `godotgame.save_system`,
`godotgame.audio_player`, `godotgame.score_label`.

## Expected results
`expected/resources.json` (produced by `harness/gen_expected.py`, measured not typed): `gdre` (real GDRE run results, listed files,
recovered sha256, diff vs src = empty), `static` (sha256 + size of every shipped file, scripts' sha256, node trees, ext/sub resources,
functions/signals/exports per script, autoload, input actions, viewport, wav header), `runtime` (explains why gameplay cannot be executed),
`features`.

## Limits (honest)
* The game cannot be executed here: no Godot engine binary is installed or redistributed.
* This is a structurally valid PCK for static analysis, not an engine-exact export: `project.godot` is stored as text (real exports hold
  `project.binary`), scenes/scripts are source form (no `.remap`/`.scn`/`.gdc`), and `beep.wav` is raw (no `.import` + `.godot/imported/*.sample`).
  A real Godot 4.3 runtime would likely refuse to load it as a game.
