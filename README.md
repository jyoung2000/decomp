# Rebuild Studio

A Windows-first desktop application (Tauri 2 + React/TypeScript UI + Python controller sidecar) that takes an application or game
installation folder, recovers what local tools can recover (rizin + rz-ghidra, ILSpy, GDRE tools, asar/JS extraction), reconstructs
it in Rust, Rust + Bevy or HTML/CSS/JS, verifies the result against the original with a deterministic verifier, and ships
`source/ dist/ evidence/ reports/` with an honest parity report. Models (BYOK or external clients over MCP) propose; the verifier decides.

* Plan and status: `PLAN.md`, `CHECKPOINT.md`
* Design: `docs/DECISIONS.md`, `docs/API.md`, `docs/SUPPORT_MATRIX.md`
* Run it: `docs/USAGE.md` · packaging: `docs/PACKAGING.md`, `docs/WINDOWS_RELEASE_GATES.md`
* Integrations: `docs/PROVIDERS.md`, `docs/HERMES.md`, `clients/`
* Demonstrations: `examples/`
* Final report: `reports/final-report.md` (generated by `scripts/final_report.py`)

Layout: `controller/` (Python: jobs, backends, verifier, API, MCP, CLI) · `ui/` (React) · `desktop/` (Tauri shell) ·
`fixtures/` (source-known acceptance fixtures with frozen oracles) · `clients/` (Claude Code / Codex / Gemini / Hermes / Cutter packages) ·
`scripts/` (install/remove, Windows build/doctor/setup).
