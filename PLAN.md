# Rebuild Studio — Implementation Plan

Status legend: `todo` | `in-progress` | `done` | `blocked` | `partial`. Milestone IDs are stable; never renumber.
Acceptance checks are executable commands or named tests. "done" requires the acceptance check to have run on this checkout.

## Host constraints (recorded 2026-10-06)
- Implementation host: Linux (Ubuntu 24.04, x86_64, 4 cores, 15 GB RAM). No interactive Windows session, no Docker daemon, no GPU.
- Reachable: pypi, npm, crates index, GitHub git/release downloads, api.github.com (scoped to jyoung2000/decomp), platform.claude.com.
- Unreachable from this host: v2.tauri.app, hermes-agent.nousresearch.com, developers.openai.com, docs.rs, crates.io web (index works).
- Consequence: every Windows-native gate (installer, WebView2, UI capture, Hermes desktop actions, Windows paths) is a handoff; see M12.
